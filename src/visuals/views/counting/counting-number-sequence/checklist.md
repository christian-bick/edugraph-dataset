### Counting Number Sequence View Checklist

1. **Instruction and Sequence:**
   - In Question Mode, the prompt "Fill in the missing number." appears above an ordered row of numeral cells. Per the global Instruction & Mode Rules, the prompt is absent in Solution Mode.
   - The visible cells form either a compact numeral row or a row of raised number tiles with countable dot quantities; exactly one layout applies per image.
2. **Missing Position:**
   - In Question Mode (`_mode-Q`), exactly one cell after the starting value is empty.
   - In Solution Mode (`_mode-S`), the same cell contains the missing numeral with solution highlighting.
3. **Layout Integrity:**
   - All cells are evenly spaced, readable, and contained within the sequence panel without overlap or clipping.
   - Arabic-numeral rows display complete one-, two-, or three-digit values through 120 inside their cells; raised physical-tile rows contain no more than six cells and show quantities through 20.
