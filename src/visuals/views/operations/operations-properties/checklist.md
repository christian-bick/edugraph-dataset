# Operations Properties Visual Checklist

- In Question Mode, the prompt asks the learner to complete the equation, and exactly one value box is empty.
- A commutative-property problem shows the same three operands in reversed order on opposite sides of the equals sign.
- An associative-property problem shows the same three operands in the same order, with the grouping changed from `(a op b) op c` to `a op (b op c)` for addition or multiplication.
- In Solution Mode, the prompt is absent and the formerly missing value appears in its original box with green solution styling.
- The property label, equation, operators, grouping symbols, and value boxes remain in the same positions in Question and Solution modes.
