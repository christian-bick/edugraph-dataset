# Shape Compose Shapes - Pedagogical Logic Checklist

- Verify that every target has a geometrically valid composition recipe: polygons use smaller polygons, circular parts use exact fractional-circle pieces, and solids use compatible solid halves or shorter solids.
- Verify that `components` contains the exact number and names of pieces stated by the correct answer.
- Verify that `options` contains the correct answer and one geometrically invalid distractor.
